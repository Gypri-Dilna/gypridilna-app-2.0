
# RFID Access Control System

This project contains the backend server and frontend UI for a complete RFID access control system.

## Project Structure

To run this application, your final project folder should have the following structure:

```
/rfid-access-control/
├── app.py              # The Python Flask server
├── requirements.txt    # Python dependencies
└── dist/               # The entire 'dist' folder generated by building the React app
    ├── index.html
    └── assets/
        ├── ... some-file.js
        └── ... some-file.css
```

## How to Run

Follow these steps to get the application running.

### Prerequisites

- **Python 3:** Make sure you have Python 3 installed. You can get it from [python.org](https://www.python.org/).
- **Node.js & npm:** Required to build the frontend application to generate the `dist` folder.

### Step 1: Build the Frontend

1.  Navigate to your frontend project directory (the one with `index.html`, `App.tsx`, etc.).
2.  Install dependencies if you haven't already:
    ```bash
    npm install
    ```
3.  Build the application. This will create the `dist` folder.
    ```bash
    npm run build
    ```

### Step 2: Set Up the Backend

1.  Create a new folder for your server (e.g., `rfid-access-control`).
2.  Place the `app.py` and `requirements.txt` files inside this new folder.
3.  Copy the entire `dist` folder from your frontend project (from Step 1) into this same server folder.

### Step 3: Install Python Dependencies

1.  Open a terminal or command prompt and navigate into your server folder (`rfid-access-control`).
2.  Create and activate a Python virtual environment. This is highly recommended to keep project dependencies isolated.

    ```bash
    # Create the virtual environment
    python -m venv venv

    # Activate it (Windows)
    .\venv\Scripts\activate

    # Activate it (macOS/Linux)
    source venv/bin/activate
    ```

3.  With the virtual environment active, install the required libraries:
    ```bash
    pip install -r requirements.txt
    ```

### Step 4: Run the Server

1.  In the same terminal with the virtual environment active, run the Flask application:
    ```bash
    python app.py
    ```
2.  On the first run, it will create a `system.db` file. This is your database.
3.  The server is now running!

### Step 5: Access the Application

1.  Open your web browser and go to `http://localhost:5000`.
2.  You should see the login screen for your RFID Access Control Dashboard.
3.  For your ESP32 hardware, send POST requests to the IP address of the computer running the server, on port 5000 (e.g., `http://192.168.1.105:5000/api/check-access`).
